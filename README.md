# money-news-station

中文商业新闻演示站（最小版本）。

## 已完成页面
- 首页 `index.html`
- 分类页 `category.html`
- 文章详情页 `article.html`

## 主要模块
- 今日重点赚钱机会
- 最新资讯
- 分类导航
- 12 条假数据（`news-data.js`）

## 本地运行
这是纯静态站点，直接用浏览器打开 `index.html` 即可。

如果你安装了 Python，也可以运行：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。
