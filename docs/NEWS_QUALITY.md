# 新闻生成质量修复

## 检查基线

基于 main 提交 `5e25ce656edb41b7ffdb7630ca30eef1b61cfa31`。检查时没有打开的 PR。

原流程：BBC商业、BBC科技及FT首页RSS → 标题/摘要英文关键词分类 → 分类优先级与新鲜度排名 → 前15条尝试翻译，取最多5条 → Google翻译，失败再用MyMemory → 按分类读取CATEGORY_COPY的三个固定字段 → 至少3条才覆盖数据 → Actions提交并发布Pages。

问题：
- 分类判断代替事件分析，同分类新闻的三个字段完全相同。
- 原文没有保存，页面把RSS摘要称为正文；不足以核验推断。
- 翻译仅以“含汉字”作为成功标准。现有数据把数据中心的site译为网站，把super-charging译为超级收费。
- 缺失/错误日期被当成当前时间；Atom的更新时间被当作发布时间。
- MyMemory静默截断450字符；单一RSS格式错误会中断整次运行。
- 原排名是相关性排序，不代表商业收益，也不证明新闻的重要程度。

## 实现

移除CATEGORY_COPY。`scripts/news_analysis.py`按原文中同一句话的事件信号生成经营验证建议，分类不参与分析。

首版覆盖六类事件：AI仿冒诈骗、数据中心参与方退出、潮汐发电原型、贵金属价格变化、工厂自动化试验、关税变化。每条保留原文证据、来源URL、规则版本与三个字段引用的证据ID。建议均标注经营推断；未匹配、否定或部分不确定表述回退为证据不足，不填充收益、需求或订单结论。

这仍是保守的事件规则系统，不是开放式全文研究器。相同事件类型会共享核查框架；规则不理解所有英语语法，否定/假设识别并不完备。后续扩充必须提供真实来源样本及反例测试，不得为了文字不同而虚构分析。金额、产量和ROI不从关键词推导。

没有新增模型API、密钥或付费依赖。保留原抓取源、分类标签、定时更新、最低3条保护及Pages部署。新增自动测试及数据证据校验。数据写入先验证再原子替换。

日期：保留RSS原始日期及带时区时间，date采用来源时间戳的日历日期。拒绝缺失、无时区、不可解析、超过72小时和超前10分钟的时间；Atom要求published。不会用抓取时间补新闻发布日期。retrieved_at另存抓取时间。

来源：候选只接受配置发布方域名的HTTPS链接；原始链接不改写，避免改变既有ID。此检查不是链接可访问性或文章真实性证明。

翻译：三个真实样本的标题及摘要作逐句精确匹配校订；原文改变后不再套用。其余继续机器翻译，并在页面标明未人工校订；不声称已解决所有翻译错误。翻译失败跳过，MyMemory不再截断原文。

## 真实样本与核验范围

2026-10-19 UTC从 `https://feeds.bbci.co.uk/news/business/rss.xml` 取得三个条目，原始条目保存在 `tests/fixtures/bbc-2026-10-18.xml`，生成结果在 `tests/fixtures/expected-news.json`。

| 事件 | RSS发布时间 UTC | 经营验证方向 |
|---|---|---|
| AI诈骗 | 2026-10-18 23:24:59 | 付款指令、账户变更、已登记号码回拨 |
| 微软退出英国AI数据中心项目 | 2026-10-18 16:46:42 | 交付承诺、项目参与方、替代方案；退出不等于取消 |
| 潮汐发电机 | 2026-10-18 08:12:24 | 独立测试、维护成本、并网；研发者说法不等于商业验证 |

三个链接与RSS逐项一致。浏览检索工具无法打开BBC文章全文；未取得正文、未独立证实事件、未确认原文网页HTTP可用性。所有分析明确只依据RSS，不能声称全文核验。BBC属于新闻发布方，这不是开发商或监管机构的第一手证明。

页面新增“依据与限制”，展示英文原文、来源发布时间及翻译状态。旧数据仍可显示；此次PR不伪造或重新日期化线上news-data.json。合并后由原日更流程生成新数据。

## 运行与验收

```sh
python -m unittest discover -s tests -v
node --check app.js
python scripts/fetch_daily_news.py  # 联网抓取，成功时覆盖当前目录news-data.json
```

单元测试不依赖网络，冻结时钟，使用真实RSS条目，验证：同分类不同事件分析不同（去掉标题锚点后仍不同）、证据对应、日期/链接、校订译文、否定/未知事件回退、坏Feed隔离、未来/过期日期拒绝、翻译失败保留旧文件、成功写入及篡改证据拒绝。

扩充建议：对新事件先保存来源的标题/摘要及时间；需要具体价格、需求或收益判断时，先接入可访问的官方公告、产品文档或统计数据，并明确引用，再增加规则。不要把本文事件规则当成全部新闻已获得深度商业分析。

## 合并与回滚

PR合并后原日更会在马来西亚时间07:07运行，也可在Actions手动运行Update News Data。原push发布工作流保持不变。测试失败或有效新闻不足3条会停止本轮，不覆盖既有新闻；可能继续展示上一轮数据。

回滚本PR提交即可恢复旧生成逻辑，Pages与历史news-data.json没有迁移要求。未在本环境执行生产部署。
